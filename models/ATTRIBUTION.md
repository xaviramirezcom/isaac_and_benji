# Body model credits

The realistic body in the Body app is built from open anatomy data, simplified (fewer triangles, packed to a small binary) for phones:

- Visible Human male reference body (skin, brain, heart, lungs, liver, kidneys, bladder, intestines, spine, pelvis) from the **Human Reference Atlas 3D Reference Library** (HuBMAP / NIH), CC BY 4.0 — https://humanatlas.io/3d-reference-library
- Stomach and ribs from **BodyParts3D**, © The Database Center for Life Science, CC BY 4.0 — https://dbarchive.biosciencedbc.jp/en/bodyparts3d/ (via the converted copy in https://github.com/ashemag/human-atlas, data CC BY 4.0).
